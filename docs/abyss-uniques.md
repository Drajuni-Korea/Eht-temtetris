## 고유효과와 옵션 구분

`effect`와 `skill`은 고유효과 설명이다. 마이다스의 골드 증가나 흡수의 갑옷의
조건부 피해 감소 등을 랜덤옵션에 자동 추가하지 않는다. `fixedOptions`만 기존
옵션 집계에 합친다. 진 질풍의 경갑은 이동속도와 랜덤옵션 3개로 총 4개이며,
OCR이 이동속도를 이미 읽었어도 중복 집계하지 않는다. 5개가 잡히면 자동등록하지
않으며, 수동등록에서도 초과 옵션을 잘라서 저장하지 않는다.

## 매칭 규칙과 호환성

- 공백을 정규화하고 긴 장비명을 먼저 비교해 진/일반 충돌을 방지한다.
- 추출한 장비명 → 헤더 → 전체 OCR 순서로 조회한다. 이름이 확정되면 부위와
  심연 단계는 장비 DB를 우선한다. 이름에 `심연`이 없어도 L 유니크로 분류한다.
- `블러디 피스트`/`블러디피스트`/기존 `블러드 피스트` 표기를 모두 허용한다.
- 혼돈 유니크와 일반 심연 장비의 기존 special 값은 유지한다.
- 저거너트는 투구다. 중복 선택 항목은 `juggernaut`로 통일하되 기존 저장 키
  `juggernautUnique`의 표시와 고정옵션은 호환한다. 저장된 인벤토리를 일괄 변경하지 않는다.

## 검증

`npm test`는 14종 이름/별칭, 혼돈 회귀, 중복 키, 고정옵션, 실제 `processJob`
함수의 등록 판정을 검증한다. 이미지 OCR 호출은 테스트에서 대체하므로 실제
스크린샷 인식률 검증과는 구분한다. 실제 장비 캡처로 진/일반 유니크 및 진 질풍의
경갑을 추가 확인해야 한다.
